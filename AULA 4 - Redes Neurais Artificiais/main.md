#Atividade 2 – Transformação de prompts

# 1. Prompt simples melhorado

```
Explique o que é inteligência artificial, como ela funciona e quais são suas principais aplicações no dia a dia.
```

# 2. Prompt RTF

```
Role: Você é um especialista em tecnologia.
Task: Explique o que é inteligência artificial, como ela funciona e onde ela é usada atualmente.
Format: Responda em tópicos simples e objetivos, com exemplos do dia a dia.
```
# 3. Prompt CRAFT

```
Context: O texto será usado por iniciantes em tecnologia.
Role: Você é um professor de inteligência artificial.
Action: Explique o que é IA, como funciona e apresente exemplos práticos do cotidiano.
Format: Organize em tópicos curtos e objetivos.
Tone: Utilize linguagem simples e didática.
```

# 4. Prompt COSTAR
```
Context: O conteúdo será utilizado em uma aula introdutória de tecnologia.
Objective: Explicar o que é inteligência artificial e suas aplicações práticas.
Style: Texto organizado e didático.
Tone: Amigável e educativo.
Audience: Estudantes iniciantes em tecnologia.
Response: Estruture em tópicos com exemplos do cotidiano.
```

# Atividade 4 – Criação de prompt profissional
# uma campanha de divulgação
# voltada para jovens
# com linguagem simples
# em formato de texto para redes sociais
```
Context (Contexto): Uma empresa quer criar uma campanha de divulgação nas redes sociais para atrair jovens e aumentar o engajamento online.

Objective (Objetivo): Produzir conteúdos criativos e modernos que chamem a atenção do público jovem e incentivem interação com a marca.

Style (Estilo): Descontraído, moderno e fácil de entender.

Tone (Tom): Divertido, leve e motivador.

Audience (Público-alvo): Jovens entre 16 e 30 anos que utilizam redes sociais diariamente.

Response (Resposta): Crie textos curtos para redes sociais contendo:

slogan da campanha;
legenda para Instagram;
texto para TikTok/Reels;
hashtag criativa;
chamada para ação (CTA);
linguagem simples e jovem.

```
